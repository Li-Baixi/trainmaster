# 使用指南：训练大师

> 一个只属于你的健身饮食 AI 教练。它记得你的一切（存在手机本地），随时问，随时拍。

## 一、iPhone 安装（添加到主屏幕）

1. 用 **Safari** 打开 App 网址（见 `部署指南-GitHub-Pages.md`）
2. 点 Safari 底部的 **分享按钮**（方框加向上箭头 ⬆︎）
3. 滚动找到 **添加到主屏幕**
4. 名称可改成「训练大师」，点 **添加**
5. 主屏幕出现图标后，点开就是全屏 App（没有浏览器地址栏）

## 二、首次使用（3 步走通）

1. **配 AI 服务**：我的 → 设置
   - 「转发地址」粘贴你部署的 Cloudflare Worker 地址（部署见 `部署指南-Cloudflare-Worker.md`）
   - 「模型服务」里填 DeepSeek 的 API Key（在 platform.deepseek.com 注册充值后创建）
   - 两个「测试」按钮都通过即可
2. **填问卷**：App 会自动带你走 5 步问卷（基本信息 → 训练条件 → 饮食 → 作息 → 生成）
3. **开始使用**：档案与计划生成后，「今天」页就有你的当日安排了

## 三、日常怎么用

### 📷 吃饭拍照
吃饭前拍一张 → App 识别食物、估算热量营养 → 告诉你结合当前计划该怎么吃（吃多少、先吃什么）→ 数字不准可以点着改 → 「记入今天」。

### 💬 随时问教练
- 「这个器械怎么用？」——配一张器械照片更好
- 「今天出差只能吃便利店，吃什么？」
- 「最近卧推一直卡在同一重量」
- 聊天记录自动存进当天日志，之后 AI 也会参考最近几天的动态

### 📋 调整计划
对话里直接说（比如「下周出差三天，帮我重排」）。教练会给出完整新计划 → 出现黄色「新计划」卡片 → **预览** → **确认应用**。旧版本自动归档，在「计划」页随时能恢复。

### 📊 看记录
「记录」页按天看餐食、热量蛋白质汇总、当天完整日志（包括聊了什么）。

## 四、数据在你手里（重要）

- 所有数据（档案/计划/日志）只存在**这台手机**里，以 **markdown 文件**形式管理
- **建议每周导出一次**：记录 → 📤 导出全部 md → 分享面板选「存储到文件」，存到 iPhone「文件」App（可再存 iCloud）
- 换手机 / 重装 / 误删时：装好 App → 设置配好 AI → 记录 → 📥 导入恢复 → 选择之前导出的 md 文件，一切回来
- App 也会提醒：超过 7 天没导出，「我的」页会出现黄色提示

## 五、AI 是怎么"记得你"的

每次对话，App 会自动把这几样发给模型（拼接在系统提示里）：
1. 你的个人档案 `profile.md`
2. 当前训练饮食计划 `plans/current.md`
3. 最近 3 天的动态摘要（吃了什么、聊了什么）——天数可在设置里改

所以你永远不用重复自我介绍。档案变了（比如体重、目标变化），对话里让教练更新，或在「我的」页直接编辑。

## 六、常见问题

| 问题 | 处理 |
|---|---|
| 发消息报"尚未配置" | 设置里补 Worker 地址 / API Key |
| 回复说"连不上" | 检查网络；Worker 地址是否正确；Cloudflare 那边服务正常吗 |
| 拍照识别不准 | 光线足一点、拍全盘子；识别结果里可以手动改数字 |
| 想换模型 | 设置 → 添加服务商（OpenAI 兼容：填 baseUrl/Key/模型名）→ 设为默认 |
| 图标/界面怪 | 确认是用 Safari「添加到主屏幕」后从主屏打开，不是浏览器里直接用 |
| 忘了导出就把 App 删了 | 数据随 App 删除而清空——所以请保持每周导出的习惯 |
